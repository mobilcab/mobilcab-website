The first session doesn’t need to cover the whole Roadmap (M1–M5). It covers the **basics**: 3D design and cut list, plus save and export. All on a laptop, in the browser.

## Before you start

- A laptop with a current browser.
- An internet connection (the app is in the cloud).
- A real project or a simple cabinet you know (for example a base unit), so you can check the list against what you expect.

No install, and no licence tied to a particular workshop machine.

## Step 1 — Account

Create an account and open the app. On the current stage, design and cut lists are available on the Free plan until we open subscriptions.

![Sign in to Mobilcab — login screen in the browser](/blog/prima-sesiune/01-cont.png)

*Entering the app from the browser: sign in or create an account.*

If you want a discount on the subscription when we open payment, the **Founding Partner** program is separate — free signup, no purchase obligation. You can use the app without joining the program.

## Step 2 — A new project

Open a project. Set the cabinet sizes and panels. Add what you use often: doors, shelves, drawers — following your own flow.

![New project in Mobilcab — furniture type, default material and edging](/blog/prima-sesiune/02-proiect.png)

*New project dialog: pick the type, material, and edging, then create the project.*

Keep the first session simple: one cabinet, not the whole kitchen. The goal is to see the project → list chain, not to finish a job site.

## Step 3 — Cut list

Open the cut list on the same project. Check the parts: sizes, quantities, materials. Compare with what you’d calculate on paper for the same cabinet.

![Cut list in Mobilcab — parts with sizes, quantities, and materials](/blog/prima-sesiune/03-debitare.png)

*Cut list from the same project: check the parts before the workshop.*

If something doesn’t match, check the project settings (board thickness, edging, how the part is fitted) — the list comes from the model, not from a separate table you forgot to update.

## Step 4 — Save

Save to the cloud. Next time you open it on the laptop, the project is there — no file moved on a stick.

![Project menu in Mobilcab — Save to cloud](/blog/prima-sesiune/04-salvare.png)

*From the Project menu: Save to cloud.*

## Step 5 — Export, if you need it

Export the list (CSV) or the project (`.mcab`) when you want a local copy or a file to pass into your current flow. Right now on Free, exports have no download limit; the 3-download limit on Free appears when we open subscriptions.

![Export from the cut list in Mobilcab — CSV download](/blog/prima-sesiune/05-export.png)

*From the cut list you export CSV; from the Project menu you can save locally or export `.mcab`.*


## What you leave for another day

- Nesting, labels, quotes — on the Atelier plan, when that stage is ready on the Roadmap.
- CNC export — a later stage.
- Team / sharing and AI — later stages.

The first session succeeds if you have a saved project and a cut list you can read in the workshop — not if you’ve walked the whole roadmap.
